# Roadmap

## Phase 0 — Concept framing
- Define problem statement
- Define target user
- Define category and terminology
- Document MVP hypothesis

## Phase 1 — Prototype interpreter
- Collect user onboarding context
- Let user create topic profiles
- Ingest reflections
- Interpret new statements with context
- Add correction loop

## Phase 2 — Personal context memory
- Introduce richer evidence retrieval
- Track profile evolution over time
- Improve topic disambiguation
- Add confidence calibration

## Phase 3 — Agent interface
- Expose a clean API for external assistants
- Add permission scopes by context type
- Enable app-specific interpretation policies

## Phase 4 — Platform and protocol
- Standardize portable personal context format
- Enable multi-agent compatibility
- Explore developer ecosystem

## Milestones

### Milestone A
Clear product memo and first demo spec.

### Milestone B
Clickable prototype with manual inputs and single-statement interpretation.

### Milestone C
Functional alpha with user correction loop.

### Milestone D
First external users and pattern validation.
