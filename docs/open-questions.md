# Open Questions

## Product
- What is the narrowest valuable first use case?
- Is the first buyer an end-user or a developer building agents?
- How much onboarding effort will users tolerate?
- What is the best UX for user correction?

## Data
- What sources should be allowed in MVP?
- Should the system ingest external content at all in the first version?
- How do we separate stable preferences from transient reactions?
- How do we handle contradictory evidence over time?

## Trust and privacy
- How do we make the model legible to the user?
- How do we let users define what stays private?
- How do we prevent overclaiming certainty about a person?
- How should sensitive domains be handled?

## Modeling
- Should scores be numeric, categorical, or both?
- What ontology of topics should be used?
- How should cultural language patterns be represented?
- How do we measure when the system interpreted something correctly?

## Commercial
- Is this initially a consumer product, a B2B API, or both?
- What is the clearest monetizable wedge?
- What product delivers value before a full agent ecosystem exists?
